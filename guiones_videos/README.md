# Plan Maestro de Grabación de Videos Tutoriales: UYAPAY B2C
## Guía Oficial para Grabación de Pantalla en Celular y Capacitación Comercial

---

### 1. Objetivo General
Este compendio de **9 Guiones Audiovisuales** sirve como pauta técnica paso a paso para que el capacitador o administrador grabe la pantalla de su dispositivo móvil (Android 13.0, 6.7") ejecutando la aplicación **UYAPAY B2C**. 

Cada video tutorial se enfoca en un proceso crítico del flujo comercial en ruta de **SOLAR**, garantizando una explicación fluida, profesional, sin improvisaciones y alineada estrictamente con las reglas de negocio del sistema.

---

### 2. Estándar de Grabación y Recomendaciones Técnicas

| Parámetro | Configuración Recomendada |
| :--- | :--- |
| **Dispositivo** | Smartphone Android 13.0 (pantalla 6.7", resolución 1080x2400 o superior). |
| **Grabador de Pantalla** | Grabador nativo de Android o app profesional (AZ Screen Recorder / XRecorder) a 1080p, 60 fps, bitrate alto (>12 Mbps). |
| **Puntero Visual / Toques** | **ACTIVAR "Mostrar toques en pantalla"** (en Opciones de Desarrollador de Android) para que los alumnos vean exactamente dónde se presiona cada botón. |
| **Audio / Locución** | Micrófono corbatero (lavalier) o auricular con cancelación de ruido. Hablar con tono seguro, pausado y vocalización clara. |
| **Notificaciones** | **Activar modo "No Molestar" (Do Not Disturb)** y cerrar apps en segundo plano para evitar banners de WhatsApp o llamadas durante el REC. |
| **Ambiente de Datos** | Conexión Wi-Fi/4G estable, GPS de alta precisión encendido, y usuario de prueba asignado con cartera del día cargada. |

### 4. Estructura de cada Guión
Cada archivo de guión contiene:
1. **Ficha Técnica:** Metadatos y objetivo pedagógico.
2. **Checklist Previo al REC:** Estado de la app, permisos y datos listos antes de grabar.
3. **Pauta de Grabación Minuto a Minuto (Tabla de 4 Columnas):**
   - **Tiempo / Momento:** Timing estimado de la escena.
   - **Acción en Pantalla:** Qué tocan tus dedos en el smartphone.
   - **Locución / Discurso Exacto:** El guión que debes hablar o doblar.
   - **Nota de Grabación / Ritmo:** Consejos de cámara, pausas y transiciones.
4. **Reglas de Negocio Clave y Prevención de Errores:** Casos borde para recalcar a los asesores.
